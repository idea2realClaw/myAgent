## 使用示例

### 查询云天化

```python
from stock_price_tool import StockPriceFetcher

fetcher = StockPriceFetcher()
```

## 常见错误

### 错误1：上海股票用 .SS 而不是 .SH

```python
# 错误：600096.SS（云天化）
# 正确：600096.SH（云天化）
```

### 错误2：港股代码位数不对

```python
# 错误：700.HK（3位）
# 正确：0700.HK（4位，前面补0）
```

### 错误3：美股加了后缀

```python
# 错误：AAPL.US
# 正确：AAPL（不加后缀）
```

### 错误4：混淆上海和深圳

```python
# 上海：6开头的股票用 .SS
# 深圳：0或3开头的股票用 .SZ

# 600036.SS（上海）
# 600036.SZ（错误）
# 300750.SZ（深圳）
# 300750.SS（错误）
```

## 代码格式转换规则

### 1. 纯数字自动识别

```python
# 6开头 → .SS（上海）
'600036' → '600036.SS'

# 0或3开头 → .SZ（深圳）
'000001' → '000001.SZ'
'300750' → '300750.SZ'

# 4-5位数字 → .HK（港股）
'0700' → '0700.HK'
'9988' → '9988.HK'
```

### 2. 字母代码不加后缀

```python
'AAPL' → 'AAPL'  # 美股
'MSFT' → 'MSFT'  # 美股
'TSLA' → 'TSLA'  # 美股
```

## 技巧提示

1. **查询前先确认**：不确定代码格式时，先用 `symbol.split('.')` 检查
2. **使用工具函数**：`StockPriceFetcher.normalize_symbol()` 会自动处理格式
3. **批量查询**：一次查询多只股票，减少API调用次数
4. **检查数据**：查看返回数据的 `source` 和 `update_time` 确认数据有效性
