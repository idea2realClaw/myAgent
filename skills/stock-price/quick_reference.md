# 股票价格查询快速参考卡

## 🎯 快速查询

### 单只股票
```
查询 腾讯
或
股票 0700.HK
```

### 多只股票
```
查询：腾讯 阿里 苹果 特斯拉
```

### 历史数据
```
历史 腾讯 5天
历史 AAPL 1月
```

---

## 📊 支持的代码格式

### A股
- 上海：600000.SS（招商银行）
- 深圳：000001.SZ（平安银行）、300750.SZ（宁德时代）
- 可省略后缀：600036 → 600036.SS

### 港股
- 标准格式：0700.HK（腾讯）
- 可省略后缀：0700 → 00700.HK

### 美股
- NASDAQ/NYSE：AAPL、TSLA、MSFT
- 可省略后缀：AAPL → AAPL.US

## ⚠️ 注意事项

1. **数据延迟**：免费数据源延迟15-30分钟
2. **非交易时间**：返回最新收盘价
3. **汇率换算**：跨境股票需关注汇率
4. **数据准确性**：建议多个数据源验证
5. **投资风险**：本工具仅提供价格信息

## 🔧 使用示例

```python
from stock_price_tool import StockPriceFetcher

fetcher = StockPriceFetcher()

# 查询单只股票
result = fetcher.get_stock_price('腾讯')
print(fetcher.format_price_output(result))

# 批量查询
df = fetcher.get_multiple_stocks(['腾讯', 'AAPL', 'TSLA'])
print(df)

# 历史数据
hist = fetcher.get_historical_data('0700.HK', '5d')
print(hist)
```
