# 旅行搜索最佳实践

## 酒店预订策略

### 提前预订时间

| 目的地类型 | 最佳预订期 | 说明 |
|-----------|-----------|------|
| 国内热门城市（北京/上海/三亚） | 提前2-4周 | 热门酒店价格波动大，早订优惠多 |
| 国内一般城市 | 提前1-2周 | 选择性多，价格合理 |
| 境外热门目的地 | 提前4-8周 | 旺季需提前锁定 |
| 商务出差 | 提前1-2周 | 固定档期，价格相对稳定 |

### 价格优惠技巧

1. **工作日入住更便宜**
   - 周一至周四价格比周末低20-30%
   - 商务区酒店周末可能降价

2. **使用价格保护**
   - Trip.com: 贵了退差价
   - Booking.com: 同价保证
   - 部分信用卡自带价格保护

3. **会员优惠**
   - 各平台会员等级折扣
   - 银行信用卡积分兑换
   - 企业协议价

4. **淡旺季规律**
   - 避开节假日、展会期
   - 淡季可升级房间类型

### 评分筛选建议

| 评分范围 | 说明 |
|---------|------|
| 9.0+ | 顶级酒店，服务无瑕疵 |
| 8.5-8.9 | 优秀酒店，性价比高 |
| 8.0-8.4 | 良好选择，注意查看差评 |
| <8.0 | 谨慎选择，重点看近期评价 |

### 位置优先级

**商务出行**:
- 1. 会议/客户地址附近
- 2. 地铁/机场交通便利
- 3. 餐饮配套完善

**休闲旅行**:
- 1. 景区步行可达
- 2. 公共交通方便
- 3. 当地特色体验

## 机票预订策略

### 出行日期选择

| 策略 | 说明 | 潜在省费 |
|------|------|---------|
| 避开周末/节假日 | 工作日价格更低 | 10-30% |
| 灵活日期±3天 | 对比附近日期价格 | 5-20% |
| 提前1-3个月 | 最佳价格窗口 | 15-40% |
| 临时抢票 | 部分航班甩座 | 20-50% |

### 航班选择建议

**直飞 vs 中转**:
- 直飞：省时省力，价格较高
- 中转：可能更便宜，注意中转时长

**时间选择**:
- 早班机：准点率高，不易延误
- 晚班机：可能便宜，但疲劳度高
- 红眼航班：大幅优惠，注意休息

**舱位选择**:
- 经济舱：性价比首选
- 升舱券：可用积分兑换
- 贵宾休息室：高端信用卡权益

### 价格提醒设置

1. **Trip.com**: 设置目标价格，降价自动通知
2. **Skyscanner**: 价格日历，看趋势图
3. **航司官网**: 会员专属优惠和闪购

## 特殊需求

### 家庭出行
- 选择家庭房/连通房
- 确认儿童加床政策
- 早餐是否包含儿童

### 商务出差
- 选择商务楼层
- 确认免费WiFi速度
- 会议室/打印服务

### 长期住宿
- 公寓式酒店更划算
- 厨房可省餐饮费
- 洗衣服务便利性

---

## 取消和改签

### 酒店政策
- 免费取消：最晚几点可取消
- 预订确认：是否收到确认邮件
- 入住凭证：保存二维码/号牌

### 航班政策
- 免费改签次数和费用
- 退票手续费比例
- 行李额度确认
- 航班延误补偿规则

---

## 安全提示

1. **官网直接预订**避免第三方风险
2. **核对入住日期**避免写错
3. **保存预订号**方便查询/取消
4. **购买旅行保险**应对意外
5. **查看近期差评**了解真实情况
